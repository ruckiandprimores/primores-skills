# Primores skills

Free skills for small businesses that get their customers from Meta ads. Each one runs inside your own Claude account and does one daily job. You stay in charge: the skills draft, you send.

Made by [Primores](https://primores.org). We run ads for businesses like yours and built these for our own clients first.

## Install

In the Claude app: Settings > Customize > Plugins > Add marketplace, then enter `ruckiandprimores/primores-skills` and install the plugin you want.

## Before you use them for your business

These skills run on your own Claude plan. Check that your plan allows business use where you live. In the EU, EEA, Switzerland and the UK, Anthropic's consumer terms (Free, Pro, Max) say: "You agree that you will not use our Services for any commercial or business purposes". There, use a Claude Team or Enterprise plan.
